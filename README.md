Resort AI Chatbot
An AI-powered chatbot designed to assist resort guests with their queries, including information about amenities, services, and the resort menu. Built to provide quick, friendly, and accurate responses to enhance the guest experience.

Features
	* 🤖 AI-driven conversational assistant for resort guests
	* 🍽️ Menu information powered by menu.json
	* ⚡ Fast and lightweight Python backend
	* 🔧 Easily customizable for different resorts or hospitality businesses

Project Structure
resort-ai-chatbot/
├── libs/              # Supporting libraries and helper modules
├── app.py             # Main application entry point
├── menu.json          # Resort menu data
├── requirements.txt   # Python dependencies
└── README.md          # Project documentation

Getting Started
Prerequisites
	* Python 3.8 or higher
	* pip (Python package manager)

Installation
	1. Clone the repository:

git clone https://github.com/ajimol960-blip/resort-ai-chatbot.git
cd resort-ai-chatbot

	2. Install the required dependencies:

pip install -r requirements.txt

	3. Run the application:

python app.py


Usage
Once the application is running, interact with the chatbot to:

	* Ask about resort amenities and services
	* Get menu recommendations
	* Receive answers to frequently asked questions
